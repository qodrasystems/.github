# Security Policy — Qodra Systems

Security and data integrity are foundational to **Qodra Systems (شركة قدرة للأنظمة)**. We take every vulnerability report seriously and appreciate responsible disclosure.

## Reporting a Vulnerability

If you discover a security vulnerability in any Qodra Systems product, service, or repository:

- **Email:** [info@qodrasystems.com](mailto:info@qodrasystems.com) (Subject: `[SECURITY] Brief Summary`)
- **Do not** open public GitHub issues for suspected security vulnerabilities.

Please include:
1. A clear description of the vulnerability and potential impact.
2. Steps to reproduce or a minimal proof of concept.
3. Affected system, endpoint, or repository version.

## Response Commitment

- **Initial acknowledgment:** within 2 business days.
- **Triage & remediation updates:** coordinated directly with the reporter until resolved.
